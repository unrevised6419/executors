# Furnica IDE Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Next.js web IDE in `apps/ide` for the Furnica (ant) language. In it, students write a program, set up the 10 × 10 grid, watch the ant run, open and save the original `.ant` files, and solve the 24 worksheet tasks. Their work is saved in the browser.

**Architecture:**
- Next.js App Router app. Everything under `/` and `/ide` renders in the browser.
- The IDE is one `useReducer` state (`ide/state.ts`), driven by:
  - a `RunController` that steps an `@repo/ant-runtime` `Run` on a timer;
  - a Monaco editor wired to `@repo/ant-grammar`;
  - pure grid-edit functions.
- Work is saved through an `ExerciseStore` interface: IndexedDB now, a cloud store later.

**Tech Stack:**
- Next.js (create-next-app defaults: TypeScript, ESLint, Tailwind CSS v4, App Router, Turbopack);
- shadcn/ui (Radix), lucide-react, next-themes, sonner;
- monaco-editor with @monaco-editor/react;
- idb;
- Vitest, Testing Library and fake-indexeddb;
- Playwright.

**Spec:** `docs/superpowers/specs/2026-10-13-ide-design.md`

## Global Constraints

- **Installers.** Every tool is added with its official installer or guide:
  - `pnpm create next-app@latest`
  - `pnpm dlx shadcn@latest init` / `add`
  - the Next.js Vitest and Playwright guides
  - `pnpm add` for libraries
- **Package.** The app lives in `apps/ide` and is named `@repo/ide`. `pnpm-workspace.yaml` lists `apps/*`.
- **Workspace packages** are consumed as `workspace:*` and listed in `transpilePackages`.
- **No server code** in version 1: no API routes, no auth, no server actions.
- **Grid:** 10 × 10, 1-based coordinates.
- **Speed:** slider positions 0..20, delay `200 − 10 · position` ms, default position 10.
- **Languages:** ro, en, ru. One switch sets both the UI language and the keyword language. Default `ro`.
- **Encodings:** windows-1250 by default, windows-1251 for `ru`, UTF-8 on request.
- **Debounces:** parse 300 ms, autosave 500 ms, plus a save when the page is hidden.
- **Exercises:** at most one per task.
- **Editing after a run:** editing the program or the grid in `done` mode returns to `setup` from the start world.
- **Commits:** Conventional Commits, ending with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Work on branch `feat/ide`.
- **Formatting:** Prettier with the repository config, applied by the lint-staged hook on commit. Code uses tabs.

## Review Focus

1. **Endless programs at maximum speed.** The page must stay responsive and Stop must end the run at once. Pinned in Task 9 (`RunController` batches at delay 0, and `stop` halts).
2. **Malformed or wrong-encoding `.ant` files.** Opening one must show an error and leave the current exercise unchanged. Pinned in Task 13 (`openProgramFile` throws `AntFileError`, and nothing is dispatched).
3. **Reloading or leaving right after typing.** At most the last 500 ms may be lost, and hiding the page saves at once. Pinned in Task 6 (`useAutosave` test with `visibilitychange`).
4. **Grid characters.** Emoji sequences and combining marks count as one character. Space, empty input, `*` and two characters are refused. Pinned in Task 4 (`placeObject` tests).
5. **Late timer callbacks.** A step report that arrives after Stop or Reset must not move the grid or change the mode. Pinned in Task 7 (reducer ignores `step` in `setup` and `done`).

```ts
/** An object pushed by a move. */
export interface Push {
	readonly char: string;
	readonly from: Point;
	readonly to: Point;
}

/** What a move would do, decided before anything changes. */
export type MoveOutcome =
	| { readonly ok: true; readonly to: Point; readonly push: Push | undefined }
	| { readonly ok: false; readonly code: "wall" }
	| {
			readonly ok: false;
			readonly code: "push-off-grid";
			readonly object: GridObject;
	  }
	| {
			readonly ok: false;
			readonly code: "push-blocked";
			readonly object: GridObject;
			readonly blocker: GridObject;
	  };

/**
 * Decides one step of the ant in `direction`: it walks into an empty cell,
 * pushes one object one cell further, or fails (ant-spec §5.9).
 */
export function planMove(
	ant: Point,
	direction: Direction,
	charAt: (p: Point) => string | undefined,
): MoveOutcome {
	const to = ahead(ant, direction);
	if (!inGrid(to)) return { ok: false, code: "wall" };
	const char = charAt(to);
	if (char === undefined) return { ok: true, to, push: undefined };
	const object = { ...to, char };
	const beyond = ahead(to, direction);
	if (!inGrid(beyond)) return { ok: false, code: "push-off-grid", object };
	const blocking = charAt(beyond);
	if (blocking !== undefined)
		return {
			ok: false,
			code: "push-blocked",
			object,
			blocker: { ...beyond, char: blocking },
		};
	return { ok: true, to, push: { char, from: to, to: beyond } };
}

export interface MoveResult {
	readonly world: World;
	readonly outcome: MoveOutcome;
}

/** Moves the ant in a world. A failed move still turns the ant, as in a run. */
export function moveAnt(world: World, direction: Direction): MoveResult {
	const cells = new Map(world.objects.map((o) => [cellIndex(o), o.char]));
	const outcome = planMove(world.ant, direction, (p) =>
		cells.get(cellIndex(p)),
	);
	if (!outcome.ok) return { world: { ...world, facing: direction }, outcome };
	const { push } = outcome;
	const objects = push
		? sortObjects(
				world.objects.map((o) =>
					o.x === push.from.x && o.y === push.from.y
						? { ...push.to, char: o.char }
						: o,
				),
			)
		: world.objects;
	return { world: { ant: outcome.to, facing: direction, objects }, outcome };
}

export function sortObjects(objects: readonly GridObject[]): GridObject[] {
	return [...objects].sort((a, b) => a.y - b.y || a.x - b.x);
}
```

```ts
function moveError(
	outcome: Extract<MoveOutcome, { ok: false }>,
	range: Range,
```

```ts
import {
	isObjectChar,
	sortObjects,
	type Point,
	type World,
} from "@repo/ant-runtime";

/** `*` marks the ant in .ant files, so it cannot be an object (ant-spec §7). */
export function isCellChar(char: string): boolean {
	return char !== "*" && isObjectChar(char);
}

const same = (a: Point, b: Point) => a.x === b.x && a.y === b.y;

/** Puts `char` in an empty cell. Refused cells and characters leave the world as is. */
export function placeObject(world: World, at: Point, char: string): World {
	if (!isCellChar(char) || same(world.ant, at)) return world;
	if (world.objects.some((o) => same(o, at))) return world;
	return {
		...world,
		objects: sortObjects([...world.objects, { ...at, char }]),
	};
}

export function clearCell(world: World, at: Point): World {
	const objects = world.objects.filter((o) => !same(o, at));
	return objects.length === world.objects.length ? world : { ...world, objects };
}

const NEXT_FACING = {
	right: "up",
	up: "left",
	left: "down",
	down: "right",
} as const satisfies Record<World["facing"], World["facing"]>;

/** The original's "Rotire" button: counter-clockwise (ant-spec §10). */
export function rotate(world: World): World {
	return { ...world, facing: NEXT_FACING[world.facing] };
}
```

```ts
	KEYWORD_SETS,
	MAX_REPEAT_COUNT,
	type BlockKind,
	type Diagnostic,
	type Expectation,
	type KeywordSet,
	type Language,
} from "@repo/ant-grammar";
import type { RuntimeError } from "@repo/ant-runtime";

interface Words {
	newline: string;
	name: string;
	number: string;
	eof: string;
	nothing: string;
	or: string;
}

const WORDS: Record<"ro" | "ru", Words> = {
	ro: {
		newline: "sfârșitul rândului",
		name: "un nume de procedură",
		number: "un număr",
		eof: "sfârșitul fișierului",
		nothing: "nimic",
		or: "sau",
	},
	ru: {
		newline: "конец строки",
		name: "имя процедуры",
		number: "число",
		eof: "конец файла",
		nothing: "ничего",
		or: "или",
	},
};

const BLOCK_ROLE = {
	repeat: "REPEAT",
	while: "WHILE",
	procedure: "PROC",
	program: undefined,
} as const;

function show(set: KeywordSet, w: Words, e: Expectation): string {
	if (e === "newline") return w.newline;
	if (e === "name") return w.name;
	if (e === "number") return w.number;
	if (e === "end of file") return w.eof;
	return set.keywords[e];
}

function closer(set: KeywordSet, block: BlockKind): string {
	const role = BLOCK_ROLE[block];
	return role === undefined
		? set.keywords.END
		: `${set.keywords.END} ${set.keywords[role]}`;
}

function list(items: string[], w: Words): string {
	if (items.length <= 1) return items[0] ?? w.nothing;
	return `${items.slice(0, -1).join(", ")} ${w.or} ${items.at(-1)}`;
}

/** A diagnostic in the student's language, with keywords in the program's language. */
export function diagnosticMessage(d: Diagnostic, language: Language): string {
	const set = KEYWORD_SETS[language];
	if (language === "en") return formatMessage(d, set);
	const w = WORDS[language];
	const q = (s: string) => (language === "ro" ? `„${s}”` : `«${s}»`);
	const ro = language === "ro";
	switch (d.code) {
		case "invalid-character":
			return ro
				? `Caracter nepermis ${q(d.text)}.`
				: `Недопустимый символ ${q(d.text)}.`;
		case "unexpected": {
			const expected = list(
				d.expected.map((e) => show(set, w, e)),
				w,
			);
			const found = d.text === "" ? show(set, w, d.found) : q(d.text);
			return ro
				? `Se aștepta ${expected}, dar este ${found}.`
				: `Ожидалось ${expected}, а найдено ${found}.`;
		}
		case "reserved-word":
			return ro
				? `${q(d.text)} este un cuvânt cheie și nu poate fi nume de procedură.`
				: `${q(d.text)} — ключевое слово, оно не может быть именем процедуры.`;
		case "trailing-text":
			return ro
				? `${q(d.text)} în plus: pe un rând este o singură instrucțiune.`
				: `Лишнее ${q(d.text)}: в строке может быть только одна команда.`;
		case "missing-end":
			return ro
				? `Lipsește ${closer(set, d.block)}.`
				: `Не хватает ${closer(set, d.block)}.`;
		case "mismatched-end":
			return ro
				? `Se aștepta ${closer(set, d.block)}, dar este ${q(d.text)}.`
				: `Ожидалось ${closer(set, d.block)}, а найдено ${q(d.text)}.`;
		case "invalid-statement":
			return ro
				? `Cu ${q(d.text)} nu poate începe o instrucțiune.`
				: `С ${q(d.text)} не может начинаться команда.`;
		case "misplaced-procedure":
			return ro
				? `Procedurile se definesc înainte de ${set.keywords.BEGIN}, în afara altor blocuri.`
				: `Процедуры определяются до ${set.keywords.BEGIN}, вне других блоков.`;
		case "missing-begin":
			return ro
				? `Lipsește ${set.keywords.BEGIN}.`
				: `Не хватает ${set.keywords.BEGIN}.`;
		case "code-after-end":
			return ro
				? `După ${set.keywords.END} nu mai poate urma nimic.`
				: `После ${set.keywords.END} ничего не может быть.`;
		case "duplicate-procedure":
			return ro
				? `Procedura ${q(d.name)} este deja definită pe rândul ${d.first.start.line}.`
				: `Процедура ${q(d.name)} уже определена в строке ${d.first.start.line}.`;
		case "undefined-procedure":
			return ro
				? `Procedura ${q(d.name)} nu există.`
				: `Процедура ${q(d.name)} не найдена.`;
		case "invalid-name":
			return ro
				? `${q(d.name)} nu este un nume valid: trebuie să înceapă cu o literă.`
				: `${q(d.name)} — недопустимое имя: оно должно начинаться с буквы.`;
		case "count-too-large":
			return ro
				? `Numărul ${d.text} este prea mare; maximul este ${MAX_REPEAT_COUNT}.`
				: `Число ${d.text} слишком большое; максимум ${MAX_REPEAT_COUNT}.`;
	}
}
```

```ts
import { LANGUAGES, type Language } from "@repo/ant-grammar";

// Per-browser conveniences. Storage can be missing or throw (private mode), so
// every access falls back to the default.

const SPEED = "furnica.speed";
const LANGUAGE = "furnica.language";
export const DEFAULT_SPEED = 10;

function read(key: string): string | null {
	try {
		return localStorage.getItem(key);
	} catch {
		return null;
	}
}

function write(key: string, value: string): void {
	try {
		localStorage.setItem(key, value);
	} catch {
		// Not saved; the default applies next time.
	}
}

export function readSpeed(): number {
	const speed = Number(read(SPEED));
```

```ts
		const db = await openDB<FurnicaDB>(name, 1, {
			upgrade(db) {
				db.createObjectStore("exercises", { keyPath: "id" }).createIndex(

		this.#db = db;
```

```ts
import { useEffect, useRef } from "react";
import type { Exercise, ExerciseStore } from "./exercise";

/** Saves `exercise` `delay` ms after its last change, and at once when the page is hidden. */
export function useAutosave(
	store: ExerciseStore,
	exercise: Exercise,
	delay = 500,
): void {
	const latest = useRef(exercise);
	const mounted = useRef(false);

	useEffect(() => {
		latest.current = exercise;
		if (!mounted.current) {
			mounted.current = true;
			return;
		}
		const timer = setTimeout(
			() => void store.save({ ...exercise, updatedAt: Date.now() }),
			delay,
		);
		return () => clearTimeout(timer);
	}, [store, exercise, delay]);

	useEffect(() => {
		const flush = () => {
			if (document.visibilityState === "hidden")
				void store.save({ ...latest.current, updatedAt: Date.now() });
		};
		document.addEventListener("visibilitychange", flush);
		return () => document.removeEventListener("visibilitychange", flush);
	}, [store]);
}
```

```ts
import type { Diagnostic, Language, Range } from "@repo/ant-grammar";
import type { RunStatus, RuntimeError, World } from "@repo/ant-runtime";
import { checkGoal, TASKS, type GoalCheck, type Task } from "@repo/ant-tasks";
import type { Exercise } from "@/storage/exercise";
import type { Mode } from "./mode";

export interface RunView {
	readonly steps: number;
	/** The source of the step just run. */
	readonly current: Range | undefined;
	readonly status: RunStatus;
	readonly error: RuntimeError | undefined;
}

export interface IdeState {
	readonly exercise: Exercise;
	/** What the grid shows: the start in setup, the run's world otherwise. */
	readonly world: World;
	readonly mode: Mode;
	readonly run: RunView | undefined;
	readonly diagnostics: readonly Diagnostic[];
	readonly goalCheck: GoalCheck | undefined;
	/** Slider position, 0..20. */
	readonly speed: number;
}

export type StepReport = { readonly world: World } & RunView;

export type IdeAction =
	| { type: "edit-source"; source: string }
	| { type: "set-start"; world: World }
	| { type: "replace-content"; source: string; start?: World }
	| { type: "set-language"; language: Language }
	| { type: "set-diagnostics"; diagnostics: readonly Diagnostic[] }
	| { type: "start-run"; paused: boolean }
	| ({ type: "step" } & StepReport)
	| { type: "pause" }
	| { type: "resume" }
	| { type: "stop" }
	| { type: "reset" }
	| { type: "set-speed"; speed: number };

export function initialState(exercise: Exercise, speed: number): IdeState {
	return {
		exercise,
		world: exercise.start,
		mode: "setup",
		run: undefined,
		diagnostics: [],
		goalCheck: undefined,
		speed,
	};
}

export function taskOf(exercise: Exercise): Task | undefined {
	return exercise.taskNumber === undefined
		? undefined
		: TASKS[exercise.taskNumber - 1];
}

const running = (mode: Mode) => mode === "running" || mode === "paused";

/** Back to setup: the grid shows the (new) start world and the last run is dropped. */
function toSetup(state: IdeState, exercise: Exercise): IdeState {
	return {
		...state,
		exercise,
		world: exercise.start,
		mode: "setup",
		run: undefined,
		goalCheck: undefined,
	};
}

export function ideReducer(state: IdeState, action: IdeAction): IdeState {
	const { exercise } = state;
	switch (action.type) {
		case "edit-source":
			if (running(state.mode) || action.source === exercise.source) return state;
			return toSetup(state, { ...exercise, source: action.source });
		case "set-start":
			if (running(state.mode)) return state;
			return toSetup(state, { ...exercise, start: action.world });
		case "replace-content":
			if (running(state.mode)) return state;
			return toSetup(state, {
				...exercise,
				source: action.source,
				start: action.start ?? exercise.start,
			});
		case "set-language":
			if (running(state.mode)) return state;
			return toSetup(state, { ...exercise, language: action.language });
		case "set-diagnostics":
			return { ...state, diagnostics: action.diagnostics };
		case "start-run":
			return {
				...state,
				world: exercise.start,
				mode: action.paused ? "paused" : "running",
				run: { steps: 0, current: undefined, status: "running", error: undefined },
				goalCheck: undefined,
				diagnostics: [],
			};
		case "step": {
			// A timer can fire after Stop or Reset; its report is stale.
			if (!running(state.mode)) return state;
			const { type: _, world, ...run } = action;
			if (run.status === "running") return { ...state, world, run };
			const task = taskOf(exercise);
			const goalCheck = task && checkGoal(world, task.goal);
			return {
				...state,
				world,
				run,
				mode: "done",
				goalCheck,
				exercise: goalCheck?.solved ? { ...exercise, solved: true } : exercise,
			};
		}
		case "pause":
			return state.mode === "running" ? { ...state, mode: "paused" } : state;
		case "resume":
			return state.mode === "paused" ? { ...state, mode: "running" } : state;
		case "stop":
			return running(state.mode) ? { ...state, mode: "done" } : state;
		case "reset":
			return toSetup(state, exercise);
		case "set-speed":
			return { ...state, speed: Math.min(20, Math.max(0, action.speed)) };
	}
}
```

```ts
import type { KeywordSet, Role } from "@repo/ant-grammar";

/** A keyword role, or the original's "END..." button, which appends END for the user to complete. */
export type KeywordButton = Role | "END_BLOCK";

export const KEYWORD_BUTTONS: readonly KeywordButton[] = [
	"BEGIN",
	"END",
	"UP",
	"DOWN",
	"LEFT",
	"RIGHT",
	"REPEAT",
	"TIMES",
	"WHILE",
	"DO",
	"IF",
	"THEN",
	"ELSE",
	"PROC",
	"AT_EDGE",
	"NOT_AT_EDGE",
	"END_BLOCK",
];

export function buttonLabel(button: KeywordButton, set: KeywordSet): string {
	return button === "END_BLOCK" ? `${set.keywords.END}...` : set.keywords[button];
}

/** Text to insert at `line`:`column` (1-based), and where the caret goes after. */
export interface Insertion {
	readonly line: number;
	readonly column: number;
	readonly text: string;
	readonly caret: { readonly line: number; readonly column: number };
}

/**
 * The original's insert buttons (ant-spec §10): BEGIN and END insert a line
 * above the caret line; every other keyword is appended to the caret line,
 * followed by a space (DO without one). Unlike the original, a space is added
 * before the keyword when the line ends in a word.
 */
export function keywordInsertion(
	button: KeywordButton,
	set: KeywordSet,
	lineText: string,
	caretLine: number,
): Insertion {
	if (button === "BEGIN" || button === "END") {
		return {
			line: caretLine,
			column: 1,
			text: `${set.keywords[button]}\n`,
			caret: { line: caretLine + 1, column: lineText.length + 1 },
		};
	}
	const word = button === "END_BLOCK" ? set.keywords.END : set.keywords[button];
	const before = lineText === "" || /\s$/u.test(lineText) ? "" : " ";
	const after = button === "DO" ? "" : " ";
	const text = `${before}${word}${after}`;
	const column = lineText.length + 1;
	return {
		line: caretLine,
		column,
		text,
		caret: { line: caretLine, column: column + text.length },
	};
}
```

```ts
import type { Program, Range } from "@repo/ant-grammar";
import { Run, type Step, type World } from "@repo/ant-runtime";
import type { StepReport } from "@/ide/state";

/** Steps per timer tick at the fastest speed, so endless runs never freeze the page. */
export const BATCH_STEPS = 500;

/** The original's speed scale: slider position 0..20, 200 − 10·position ms per step. */
export function delayFor(speed: number): number {
	return 200 - 10 * speed;
}

const rangeOf = (step: Step): Range =>
	step.kind === "error" ? step.error.range : step.range;

/** Drives one `Run` on a timer and reports the grid after each tick. */
export class RunController {
	readonly #report: (report: StepReport) => void;
	#run: Run | undefined;
	#timer: ReturnType<typeof setTimeout> | undefined;
	#delay = 100;
	#paused = false;

	constructor(report: (report: StepReport) => void) {
		this.#report = report;
	}

	start(
		program: Program,
		world: World,
		options: { delay: number; paused: boolean },
	): void {
		this.stop();
		this.#run = new Run(program, { world });
		this.#delay = options.delay;
		this.#paused = options.paused;
		if (!this.#paused) this.#schedule();
	}

	setDelay(ms: number): void {
		this.#delay = ms;
	}

	pause(): void {
		this.#paused = true;
		this.#clear();
	}

	resume(): void {
		if (this.#run?.status !== "running") return;
		this.#paused = false;
		this.#schedule();
	}

	stepOnce(): void {
		if (this.#run?.status === "running") this.#advance(1);
	}

	stop(): void {
		this.#clear();
		this.#run = undefined;
	}

	#schedule(): void {
		this.#clear();
		this.#timer = setTimeout(() => {
			this.#timer = undefined;
			this.#advance(this.#delay === 0 ? BATCH_STEPS : 1);
			if (!this.#paused && this.#run?.status === "running") this.#schedule();
		}, this.#delay);
	}

	#clear(): void {
		if (this.#timer !== undefined) clearTimeout(this.#timer);
		this.#timer = undefined;
	}

	#advance(count: number): void {
		const run = this.#run;
		if (!run) return;
		let last: Step | undefined;
		for (let i = 0; i < count && run.status === "running"; i++) last = run.step();
		this.#report({
			world: run.world,
			steps: run.steps,
			current: last && rangeOf(last),
			status: run.status,
			error: run.error,
		});
	}
}
```

```js
// Converts the original's ant sprites (8-bit BMP) into PNGs with the
// bottom-left colour made transparent, as the Delphi controls drew them.
// Usage: node scripts/sprites.mjs
import { readFileSync, writeFileSync, mkdirSync } from "node:fs";
import { deflateSync, crc32 } from "node:zlib";

const SOURCE = new URL("../../../packages/ant-spec/evidence/images/", import.meta.url);
const TARGET = new URL("../public/sprites/", import.meta.url);
const NAMES = { sus: "up", jos: "down", stinga: "left", dreapta: "right" };

function readBmp(bytes) {
	const view = new DataView(bytes.buffer, bytes.byteOffset, bytes.byteLength);
	const offset = view.getUint32(10, true);
	const width = view.getInt32(18, true);
	const height = view.getInt32(22, true);
	if (view.getUint16(28, true) !== 8 || height <= 0) throw new Error("expected a bottom-up 8-bit BMP");
	const palette = 14 + view.getUint32(14, true);
	const stride = Math.ceil(width / 4) * 4;
	const transparent = bytes[offset];
	const rgba = Buffer.alloc(width * height * 4);
	for (let y = 0; y < height; y++)
		for (let x = 0; x < width; x++) {
			const index = bytes[offset + (height - 1 - y) * stride + x];
			const p = palette + index * 4;
			const o = (y * width + x) * 4;
			rgba[o] = bytes[p + 2];
			rgba[o + 1] = bytes[p + 1];
			rgba[o + 2] = bytes[p];
			rgba[o + 3] = index === transparent ? 0 : 255;
		}
	return { width, height, rgba };
}

function chunk(type, data) {
	const head = Buffer.alloc(8);
	head.writeUInt32BE(data.length, 0);
	head.write(type, 4, "ascii");
	const crc = Buffer.alloc(4);
	crc.writeUInt32BE(crc32(Buffer.concat([head.subarray(4), data])) >>> 0, 0);
	return Buffer.concat([head, data, crc]);
}

function png({ width, height, rgba }) {
	const header = Buffer.alloc(13);
	header.writeUInt32BE(width, 0);
	header.writeUInt32BE(height, 4);
	header.set([8, 6, 0, 0, 0], 8); // 8-bit RGBA
	const rows = Buffer.alloc((width * 4 + 1) * height);
	for (let y = 0; y < height; y++)
		rgba.copy(rows, y * (width * 4 + 1) + 1, y * width * 4, (y + 1) * width * 4);
	return Buffer.concat([
		Buffer.from([0x89, 0x50, 0x4e, 0x47, 0x0d, 0x0a, 0x1a, 0x0a]),
		chunk("IHDR", header),
		chunk("IDAT", deflateSync(rows)),
		chunk("IEND", Buffer.alloc(0)),
	]);
}

mkdirSync(TARGET, { recursive: true });
for (const [from, to] of Object.entries(NAMES)) {
	const image = readBmp(readFileSync(new URL(`${from}.bmp`, SOURCE)));
	writeFileSync(new URL(`${to}.png`, TARGET), png(image));
	console.log(`${from}.bmp -> sprites/${to}.png (${image.width}×${image.height})`);
}
```

```tsx
						"flex items-center justify-center rounded-sm border bg-card font-mono leading-none",

						state === "misplaced" && "border-destructive bg-destructive/10",
						onCellClick && !isAnt && "cursor-pointer hover:bg-accent",

						<button
							key={key(p)}
							type="button"
							aria-label={key(p)}

							className={className}

						</button>
					) : (
						<div key={key(p)} aria-label={key(p)} data-state={state} className={className}>

						</div>

				}),
			])}
```

```tsx
"use client";

import Editor, { loader } from "@monaco-editor/react";
import * as monaco from "monaco-editor";
import { useEffect, useRef, useState } from "react";
import { useTheme } from "next-themes";
import type { Diagnostic, Language, Range } from "@repo/ant-grammar";
import type { RuntimeError } from "@repo/ant-runtime";
import { diagnosticMessage, runtimeErrorMessage } from "@/i18n/errors";
import { languageId, setupMonaco } from "./monaco-setup";

// Use the bundled Monaco, never the CDN, so the IDE works offline.
loader.config({ monaco });
setupMonaco(monaco);

function marker(range: Range, message: string): monaco.editor.IMarkerData {
	const empty =
		range.end.line === range.start.line && range.end.column <= range.start.column;
	return {
		startLineNumber: range.start.line,
		startColumn: range.start.column,
		endLineNumber: range.end.line,
		endColumn: empty ? range.start.column + 1 : range.end.column,
		message,
		severity: monaco.MarkerSeverity.Error,
	};
}

const toMonaco = (r: Range) =>
	new monaco.Range(r.start.line, r.start.column, r.end.line, r.end.column);

export function AntEditor({
	value,
	language,
	readOnly,
	diagnostics,
	runError,
	current,
	onChange,
	onEditor,
}: {
	value: string;
	language: Language;
	readOnly: boolean;
	diagnostics: readonly Diagnostic[];
	runError: RuntimeError | undefined;
	current: Range | undefined;
	onChange: (value: string) => void;
	onEditor?: (editor: monaco.editor.IStandaloneCodeEditor) => void;
}) {
	const { resolvedTheme } = useTheme();
	const [editor, setEditor] = useState<monaco.editor.IStandaloneCodeEditor>();
	const decorations = useRef<monaco.editor.IEditorDecorationsCollection>(undefined);

	useEffect(() => {
		const model = editor?.getModel();
		if (!model) return;
		monaco.editor.setModelMarkers(model, "furnica", [
			...diagnostics.map((d) => marker(d.range, diagnosticMessage(d, language))),
			...(runError ? [marker(runError.range, runtimeErrorMessage(runError, language))] : []),
		]);
	}, [editor, diagnostics, runError, language]);

	useEffect(() => {
		if (!editor) return;
		decorations.current ??= editor.createDecorationsCollection();
		if (!current) {
			decorations.current.clear();
			return;
		}
		decorations.current.set([
			{ range: toMonaco(current), options: { inlineClassName: "furnica-current" } },
			{
				range: toMonaco(current),
				options: { isWholeLine: true, className: "furnica-current-line" },
			},
		]);
		editor.revealLineInCenterIfOutsideViewport(current.start.line);
	}, [editor, current]);

	return (
		<Editor
			height="100%"
			language={languageId(language)}
			theme={resolvedTheme === "dark" ? "furnica-dark" : "furnica-light"}
			value={value}
			onChange={(v) => onChange(v ?? "")}
			onMount={(e) => {
				setEditor(e);
				onEditor?.(e);
			}}
			options={{
				readOnly,
				minimap: { enabled: false },
				fontSize: 14,
				tabSize: 2,
				insertSpaces: true,
				automaticLayout: true,
				scrollBeyondLastLine: false,
				quickSuggestions: false,
				wordBasedSuggestions: "off",
			}}
		/>
	);
}
```

```tsx
"use client";

import { Component, Fragment, type ReactNode } from "react";

/** Shows `fallback` when the editor throws, and remounts it on retry. */
export class EditorBoundary extends Component<
	{ fallback: (retry: () => void) => ReactNode; children: ReactNode },
	{ failed: boolean; attempt: number }
> {
	override state = { failed: false, attempt: 0 };

	static getDerivedStateFromError() {
		return { failed: true };
	}

	override render() {
		if (this.state.failed)
			return this.props.fallback(() =>
				this.setState((s) => ({ failed: false, attempt: s.attempt + 1 })),
			);
		return <Fragment key={this.state.attempt}>{this.props.children}</Fragment>;
	}
}
```

```ts
import type { Language } from "@repo/ant-grammar";
import { readAntFile, type AntFileEncoding } from "@repo/ant-file";
import type { World } from "@repo/ant-runtime";
import type { Messages } from "@/i18n/messages";
import type { Exercise } from "@/storage/exercise";

/** The original wrote the system code page: Russian systems used windows-1251. */
export function defaultEncoding(language: Language): AntFileEncoding {
	return language === "ru" ? "windows-1251" : "windows-1250";
}

export interface OpenedFile {
	readonly source: string;
	/** Absent for program-only files, which keep the current grid. */
	readonly start?: World;
}

/**
 * Reads a `.ant` file (world and program, in `encoding`) or any other file as
 * UTF-8 program text, such as the `.antp` solutions.
 *
 * @throws AntFileError when a `.ant` file is malformed.
 */
export function openProgramFile(
	name: string,
	bytes: Uint8Array,
	encoding: AntFileEncoding,
): OpenedFile {
	if (name.toLowerCase().endsWith(".ant")) {
		const { world, source } = readAntFile(bytes, { encoding });
		return { source, start: world };
	}
	return { source: new TextDecoder("utf-8").decode(bytes).replace(/\r\n?/g, "\n") };
}

function slug(text: string): string {
	return text
		.normalize("NFKD")
		.replace(/\p{M}/gu, "")
		.toLowerCase()
		.replace(/[^a-z0-9а-яё]+/gu, "-")
		.replace(/^-|-$/g, "");
}

export function saveFileName(exercise: Exercise, t: Messages): string {
	const base =
		exercise.taskNumber !== undefined
			? t.task(exercise.taskNumber)
			: exercise.title || t.newProgram;
	return `${slug(base) || "program"}.ant`;
}

export function downloadBytes(bytes: Uint8Array, name: string): void {
	const url = URL.createObjectURL(
		new Blob([bytes as BlobPart], { type: "application/octet-stream" }),
	);
	const a = document.createElement("a");
	a.href = url;
	a.download = name;
	a.click();
	setTimeout(() => URL.revokeObjectURL(url), 0);
}
```

```tsx
/** Promise-based confirm and alert dialogs; render `element` once. */
export function useDialogs(t: Messages) {
	const [pending, setPending] = useState<Pending | null>(null);

	const confirm = useCallback(
		(title: string, body?: string, action?: string) =>
			new Promise<boolean>((resolve) =>

				setPending({ kind: "alert", title, body, resolve: () => resolve() }),
			),
		[],
	);

	const close = (ok: boolean) => {
		pending?.resolve(ok);
		setPending(null);
	};

	const element = (
		<AlertDialog open={pending !== null} onOpenChange={(open) => !open && close(false)}>
			<AlertDialogContent>
				<AlertDialogHeader>
					<AlertDialogTitle>{pending?.title}</AlertDialogTitle>
					{pending?.body && (
						<AlertDialogDescription>{pending.body}</AlertDialogDescription>
					)}
				</AlertDialogHeader>
				<AlertDialogFooter>
					{pending?.kind === "confirm" && (
						<AlertDialogCancel onClick={() => close(false)}>{t.cancel}</AlertDialogCancel>
					)}
					<AlertDialogAction onClick={() => close(true)}>
						{pending?.action ?? t.ok}
					</AlertDialogAction>
				</AlertDialogFooter>
			</AlertDialogContent>
		</AlertDialog>
	);

	return { confirm, alert, element };
}
```

```tsx
		dispatch({ type: "set-diagnostics", diagnostics: result.diagnostics });
		return result;

		if (!program) {
			toast.error(t.syntaxErrors(diagnostics.length));
			return false;
		}
		dispatch({ type: "start-run", paused });
		controller.start(program, exercise.start, { delay: delayFor(state.speed), paused });

			if (await dialogs.confirm(t.confirmNew)) router.push("/ide");

			const { diagnostics } = parseNow();
			if (diagnostics.length === 0) toast.success(t.syntaxOk);
			else toast.error(t.syntaxErrors(diagnostics.length));
		},
		onRun: () => {
			if (mode === "paused") {
				dispatch({ type: "resume" });
				controller.resume();
			} else begin(false);
		},
		onStep: () => {
			if (mode === "paused") controller.stepOnce();
			else if (begin(true)) controller.stepOnce();
		},
		onStop: () => {
			controller.stop();
			dispatch({ type: "stop" });

			dispatch({ type: "reset" });

			return;

			button,
			KEYWORD_SETS[language],
			model.getLineContent(position.lineNumber),
			position.lineNumber,
		);
		e.executeEdits("keyword", [
			{
				range: {
					startLineNumber: ins.line,
					startColumn: ins.column,
					endLineNumber: ins.line,
					endColumn: ins.column,
				},
				text: ins.text,
			},
		]);
		e.setPosition({ lineNumber: ins.caret.line, column: ins.caret.column });
		e.focus();
	}

	const showGoal = mode === "done" && state.goalCheck;

	return (

				enabled={enabled}

				actions={actions}

						disabled={!enabled.file}

				}

						size="sm"
```

```ts
import { useEffect, useRef, useState } from "react";
import { useRouter } from "next/navigation";
import { TASKS } from "@repo/ant-tasks";
import { MESSAGES } from "@/i18n/messages";
import { readLanguage } from "@/lib/preferences";
import { newExercise, type Exercise, type ExerciseStore } from "@/storage/exercise";

export type Loaded =
	| { status: "loading" }
	| { status: "ready"; exercise: Exercise }
	| { status: "not-found" };

/** Resolves `/ide?task=N`, `/ide?id=…` or `/ide` to an exercise, creating it when needed. */
export function useExercise(
	store: ExerciseStore | undefined,
	query: { id: string | null; task: string | null },
): Loaded {
	const router = useRouter();
	const [loaded, setLoaded] = useState<Loaded>({ status: "loading" });
	// React runs effects twice in development. Reusing the exercise created
	// for a query keeps that from saving two new exercises.
	const created = useRef(new Map<string, Exercise>());
	const once = (key: string, make: () => Exercise) => {
		let exercise = created.current.get(key);
		if (!exercise) {
			exercise = make();
			created.current.set(key, exercise);
		}
		return exercise;
	};

	useEffect(() => {
		if (!store) return;
		let alive = true;
		const done = (l: Loaded) => alive && setLoaded(l);
		setLoaded({ status: "loading" });
		void (async () => {
			const language = readLanguage();
			const taskNumber = Number(query.task);
			if (query.task !== null) {
				if (!TASKS.some((t) => t.number === taskNumber)) return done({ status: "not-found" });
				let exercise = await store.findByTask(taskNumber);
				if (!exercise) {
					exercise = once(`task-${taskNumber}`, () => newExercise({ language, taskNumber }));
					await store.save(exercise);
				}
				return done({ status: "ready", exercise });
			}
			if (query.id !== null) {
				const exercise = await store.load(query.id);
				return done(exercise ? { status: "ready", exercise } : { status: "not-found" });
			}
			const exercise = once("new", () =>
				newExercise({ language, title: MESSAGES[language].newProgram }),
			);
			await store.save(exercise);
			if (alive) router.replace(`/ide?id=${exercise.id}`);
		})();
		return () => {
			alive = false;
		};
		// eslint-disable-next-line react-hooks/exhaustive-deps -- `once` only reads a ref
	}, [store, query.id, query.task, router]);

	return loaded;
}
```

```tsx
import { readLanguage } from "@/lib/preferences";
import type { ExerciseSummary } from "@/storage/exercise";
import { useStore } from "@/storage/StoreProvider";

export function Home() {
	const opened = useStore();
	const [language, setLanguage] = useState<Language>("ro");
	const [list, setList] = useState<ExerciseSummary[]>([]);
	const t = MESSAGES[language];
	const dialogs = useDialogs(t);

	useEffect(() => setLanguage(readLanguage()), []);
	useEffect(() => {
		if (opened) void opened.store.list().then(setList);
	}, [opened]);

	const solved = new Set(list.filter((e) => e.solved).map((e) => e.taskNumber));
	const free = list.filter((e) => e.taskNumber === undefined);

	async function remove(id: string) {
		if (!opened || !(await dialogs.confirm(t.confirmRemove))) return;
		await opened.store.remove(id);
		setList(await opened.store.list());
	}

	return (
		<main className="mx-auto flex max-w-5xl flex-col gap-8 p-4 sm:p-8">
			<h1 className="text-3xl font-bold">{t.appName}</h1>
			<section className="flex flex-col gap-3">
				<h2 className="text-xl font-semibold">{t.tasks}</h2>
				<div className="grid grid-cols-2 gap-2 sm:grid-cols-4 lg:grid-cols-6">
					{TASKS.map((task) => (
						<Link key={task.number} href={`/ide?task=${task.number}`}>
							<Card className="hover:bg-accent">
								<CardHeader>
									<CardTitle className="flex items-center justify-between text-base">
										{t.task(task.number)}
										{solved.has(task.number) && (
											<CheckCircle2 aria-label={t.solved} className="size-4 text-green-600" />
										)}
									</CardTitle>
								</CardHeader>
							</Card>
						</Link>
					))}
				</div>
			</section>
			<section className="flex flex-col gap-3">
				<div className="flex items-center justify-between">
					<h2 className="text-xl font-semibold">{t.myPrograms}</h2>
					<Button asChild>
						<Link href="/ide">
							<Plus />
							{t.freeProgram}
						</Link>
					</Button>
				</div>
				{free.length === 0 ? (
					<p className="text-muted-foreground">{t.noPrograms}</p>
				) : (
					<ul className="divide-y rounded-md border">
						{free.map((e) => (
							<li key={e.id} className="flex items-center justify-between px-3 py-2">
								<Link className="hover:underline" href={`/ide?id=${e.id}`}>
									{e.title || t.newProgram}
								</Link>
								<Button
									variant="ghost"
									size="icon"
									aria-label={t.remove}
									onClick={() => void remove(e.id)}
								>
									<Trash2 />
								</Button>
							</li>
						))}
					</ul>
				)}
			</section>
			{dialogs.element}
		</main>
	);
}
```

```ts
import { readFileSync } from "node:fs";
import { expect, test, type Page } from "@playwright/test";

const repo = new URL("../../../", import.meta.url);
const read = (path: string) => readFileSync(new URL(path, repo));

test.beforeEach(async ({ page }) => {
	await page.addInitScript(() => localStorage.setItem("furnica.speed", "20"));

async function openFile(page: Page, name: string, buffer: Buffer) {
	await page.getByTestId("open-file").setInputFiles({ name, mimeType: "text/plain", buffer });
}

test("solves task 1 with its worksheet solution", async ({ page }) => {
	await page.goto("/ide?task=1");
	await openFile(page, "sarcina-01.antp", read("packages/ant-tasks/solutions/sarcina-01.antp"));
	await page.getByRole("button", { name: "Execută" }).click();
	await expect(page.getByText("Rezolvat!")).toBeVisible({ timeout: 20_000 });
	await expect(page.getByTestId("mode")).toHaveText("Terminat");

for (const [name, encoding] of [
	["spec-example.ant", "windows-1250"],
	["mamatata.ant", "windows-1250"],
	["romanian.ant", "windows-1250"],
	["russian.ant", "windows-1251"],
] as const) {
	test(`opens and saves ${name} byte for byte`, async ({ page }) => {
		await page.goto("/ide");
		await page.waitForURL(/\/ide\?id=/);
		await page.getByRole("button", { name: "Fișier" }).click();
		await page.getByRole("menuitemradio", { name: encoding, exact: true }).click();
		const bytes = read(`packages/ant-file/tests/fixtures/${name}`);
		await openFile(page, name, bytes);
		await page.getByRole("button", { name: "Fișier" }).click();
		const download = page.waitForEvent("download");
		await page.getByRole("menuitem", { name: "Salvează" }).click();
		const saved = readFileSync(await (await download).path());
		expect(saved.equals(bytes)).toBe(true);
	});
}
```

````markdown
# @repo/ide

Web IDE for the Furnica (ant) language. Write a program, set up the 10 × 10 grid, watch the ant run, open and save the original `.ant` files, and solve the 24 tasks of the "Sarcina Furnica" worksheet.

```sh
pnpm --filter @repo/ide dev      # http://localhost:3000
pnpm --filter @repo/ide test     # unit and component tests (Vitest)
pnpm --filter @repo/ide e2e      # end-to-end tests (Playwright)
pnpm --filter @repo/ide build
```

- **Editor:** Monaco, bundled locally, with highlighting and errors from [`@repo/ant-grammar`](../../packages/ant-grammar).
- **Runs:** [`@repo/ant-runtime`](../../packages/ant-runtime), stepped by `ide/run/run-controller.ts` at the original's speed scale (200 − 10 · position ms).
- **Files:** [`@repo/ant-file`](../../packages/ant-file). `.ant` files are read and written in windows-1250, or in windows-1251 for Russian. Other files are read as UTF-8 program text.
- **Tasks:** [`@repo/ant-tasks`](../../packages/ant-tasks). Each task's goal is checked after every run.
- **Saving:** exercises are saved in IndexedDB through the `ExerciseStore` interface (`storage/exercise.ts`). A cloud store can replace it later without changing the UI.

The design is in [`docs/superpowers/specs/2026-10-13-ide-design.md`](../../docs/superpowers/specs/2026-10-13-ide-design.md).
````
