# @repo/ant-tasks

Tasks for the Furnica (ant) language, with a goal check and a reference solution for each.

## The "Sarcina Furnica" worksheet

A Moldovan school worksheet of 24 tasks for the original program, published by Liceul Teoretic Nicolae Mihai with the program itself. Every task starts from the same world, the ant top-left and `mamatata` in row 2:

```
@.........
.mamatata.
```

and asks for the eight letters to be pushed into a layout, such as task 1:

```
..........
..........
..........
..........
..........
..........
m........t
a........a
m........t
a........a
```

The worksheet holds only screenshots, so `START` and the 24 goals in [`src/tasks.ts`](src/tasks.ts) were read from them. The start's facing (left) comes from the ant sprite.

```ts
import { parse } from "@repo/ant-grammar";
import { runProgram } from "@repo/ant-runtime";
import { checkGoal, START, TASKS } from "@repo/ant-tasks";

const { program } = parse(source, { language: "ro" });
const { world } = runProgram(program!, { world: START });
const { solved, missing, misplaced } = checkGoal(world, TASKS[0]!.goal);
```

`checkGoal` compares letters only: the ant may end anywhere, and equal letters are interchangeable.

## Solutions

`solutions/sarcina-NN.antp` solves task NN, in Romanian. They were generated by a search that places one letter at a time, so they are correct, not short or elegant: each letter's moves follow a comment naming its goal cell, and runs of three or more equal moves become a `REPETA`.

## Tests

Every goal holds the start's eight letters, and every solution parses, runs from `START` without errors and solves its task.
